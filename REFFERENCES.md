# References

These references guide product and architecture decisions; they are not asset,
code, or content sources.

1. **Terraria** (Re-Logic, 2011) — the primary reference for a readable 2D
   world, tile-oriented exploration, collision-driven interaction, progression,
   and host/server-authoritative cooperative multiplayer.
2. **The Sims 3 for Windows** (Maxis, 2009) — the primary reference from The
   Sims series for composable actor traits, needs, skills, autonomous behavior,
   and simulation systems that can grow independently.
